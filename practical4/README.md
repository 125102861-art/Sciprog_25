# Computing and integrating tan(x) using arrays and the Trapezoidal Rule
The aim is to calculate the values of tan(x) for angles between 0° and 60° at 5° intervals. Then stmate the area under the curve y = tan(x) between those limits using the Trapezoidal Rule, then compares the result to the exact analytical value, which is log(2).

So first we compute pi, later we generate and print tan(x) values, after this, we compute the numerical integral using the Trapezoidal Rule. Finally, we compare the result to the analytical value and display the absolute error.

Then run the executable using ./
